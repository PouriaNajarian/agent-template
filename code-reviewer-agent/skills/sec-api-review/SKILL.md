# Skill: API Review

## Used By
- [[protocol-analysis]]
- [[web-security]]

## Description
Design-level review of API architecture and implementation to identify security design flaws and implementation issues.

## Key Areas
- API design pattern review (RESTful conventions, GraphQL schema design)
- Authentication architecture review
- Authorization model assessment (scope, token, role design)
- Input validation and output encoding strategy
- Error handling and information disclosure
- API versioning and backward compatibility security
- Rate limiting and throttling architecture
- Webhook and callback security design
- Data minimization and exposure control
- API gateway and proxy configuration review

## Methodology
1. Review API documentation and schema definitions
2. Assess authentication and authorization architecture
3. Review input/output handling patterns
4. Evaluate error handling and information exposure
5. Document design-level recommendations
