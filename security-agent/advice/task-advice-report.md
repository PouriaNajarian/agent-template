2. Threat model: STRIDE/PASTA, trust boundaries (`threat-modeling-expert`).
3. SAST scan (`security-scanning-security-sast`, `skyrxin-sast-mcp-server`).
4. API + auth review (`api-security-testing`, `sec-api-security`).
5. Dependencies + supply chain (`security-scanning-security-dependencies`, `supply-chain-security`).
6. Secrets scan (`sec-secret-detection`).
7. Agent/MCP layer review (`llm-security`, `mcpshield`, `owasp-agentic-security-mcp`).
8. Validate findings (`exploitability-validation`).
9. Write severity-ranked report + residual risk (`sec-report-writing`); verify before completing.
