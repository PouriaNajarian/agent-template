# Skill: Report Writing

## Used By
- [[reporting]]
- [[security-documentation]]

## Description
Technical and executive security report writing with structured formatting, evidence presentation, and actionable recommendations.

## Key Areas
- Executive summary construction (risk posture, key findings, business impact)
- Technical finding structure (title, description, impact, reproduction, remediation)
- Evidence presentation (screenshots, command output, HTTP traces)
- CVSS v3.1/v4.0 scoring methodology
- Risk matrix and severity heatmap generation
- Remediation roadmap with priority and effort estimation
- Compliance mapping (PCI-DSS, SOC 2, ISO 27001, NIST)
- Attack timeline and kill chain visualization
- Responsible disclosure report formatting
- Lessons learned documentation

## Methodology
1. Organize findings by severity and category
2. Write executive summary for leadership audience
3. Document each finding with complete evidence chain
4. Assign CVSS scores and business impact ratings
5. Create prioritized remediation roadmap
6. Map findings to compliance frameworks
7. Generate final formatted report
