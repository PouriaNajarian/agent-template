# Security Audit (Cloudflare)

> Source: [mcpservers.org/agent-skills/cloudflare/security-audit](https://mcpservers.org/agent-skills/cloudflare/security-audit)
> Author: Cloudflare (official)

## Description
Security audit of a codebase — web apps, APIs, services, CLI tools, libraries, daemons, and more. Use when asked to find security bugs, do a security review, or harden code against common attack vectors.

## Key Areas
- Input validation and sanitization
- Authentication and authorization flaws
- Secrets and credentials exposure
- Injection vulnerabilities (SQL, XSS, command injection)
- SSRF and CSRF vulnerabilities
- Rate limiting and abuse prevention
- Dependency vulnerabilities
- Configuration security (CSP, headers, TLS)

## When to Use
- Security review of codebase
- Finding security bugs
- Hardening code against attacks
- Pre-deployment security audit
